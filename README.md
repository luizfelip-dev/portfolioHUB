## 🚀 Projeto em destaque — Studio em Dia

**Gestão financeira e de atendimentos para maquiadoras.**

O **Studio em Dia** é uma aplicação web responsiva para organizar agenda, clientes, pagamentos, produtos, despesas e resultados mensais. Desenvolvi o projeto com apoio de ferramentas de **IA durante a programação e o refinamento da interface**, integrando tecnologias modernas para resolver necessidades do dia a dia.

**Funcionalidades:** agenda de atendimentos, cadastro de clientes, controle de recebimentos, despesas e produtos, indicadores financeiros e relatórios mensais.

**Tecnologias:** React 19 · TypeScript · Supabase · GitHub Pages
